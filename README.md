## Технологии
В данном проекте использовались такие технологии, как:
- React
- React Router
- SCSS
- Axios

## Запуск
Если ты смотришь это приложение из GitHub, то вот инструкция:
1. Склонировать репозиторий: git clone https://github.com/CuriousIrbis/aragorn.git
2. Загрузить все необходимые зависимости: npm i
3. Запустить приложение: npm run dev
4. Перейти на локальный адрес: http://localhost:5173
